## Details

This revision of SMPTE RDD 55, the carriage of ARRI camera system metadata in MXF, updates the 2022 edition for ARRI cameras and software released since, including ARRICORE recording. It adds a set for named, versioned image processing parameter tables; per-frame selection of color correction tables by ND filter; six uncompensated lens items; per-frame data from ancillary devices; a secondary image checksum; and version items for the image processing and video codec. The JSON schemas of Annex C are corrected and extended to match. A redline against RDD 55:2022 accompanies the draft. Implementers of software that reads or writes ARRI camera metadata are encouraged to review it and comment through the issue tracker of this repository.
